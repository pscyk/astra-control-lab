FAILURE ANALYSIS

Grasp and placement failures

The residual repairs 53 base failures but causes four regressions. Random search already supplies much of the gain over the base: RL wins 16 pairs and loses four against that control. The remaining grasp failures need a different intervention because the residual only changes later poses.

The feedback run opens one drawer that the one-shot run does not, at a cost of eight extra calls. Its first returned observation is not bitwise identical to the baseline's. This is a useful development case, not a controlled estimate of a general feedback benefit.

The studies do not test a combined feedback-plus-residual policy. Native success does not establish safe contact, and these records provide no full-suite or real-robot result.

04 / REPRODUCTION

Check the saved results

Python 3.10 or later; the main package uses only the standard library.

python3 -m astra_lab verify
python3 -m astra_lab report
python3 -m astra_lab replay-training
python3 -m unittest discover -s tests -v

The commands check exported records and replay saved training updates. New robot episodes require the original simulator setup and model access, which this package does not include. The historical model alias is gpt-6-astra; the logs do not attest an immutable backend checkpoint.
