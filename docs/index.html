WHAT WE LEARNED

A placement fix is not a grasp fix.

The residual repaired 53 failures and caused four regressions. It cannot recover an object that was never grasped. A new observation can help, but extra calls add latency. The next test should decide when to apply a correction—not apply it everywhere.

The loop study is separate from the 200-scene dish study. It also changed the prompt and depth feedback. The first returned drawer observation was not bitwise identical. These are not compute-matched causal results.
